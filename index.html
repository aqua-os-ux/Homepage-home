How to make it your Homepage

iOS / Safari

  • Go to the App Store and download the Homepage extension
  • Go to Settings → Safari → Extensions and enable it
  • Open the extension and enter the URL of your chosen version

Microsoft Edge

  • Install the Custom New Tab extension by Maljur from the Edge Web Store
  • Copy your chosen TV Home URL
  • Paste it in the extension settings and save
  • Close and reopen Edge

Firefox

  • Press Ctrl + Shift + A to open Add-ons
  • Install the New Tab Homepage extension
  • Go to Settings → Home and set custom URLs
  • Paste your chosen TV Home URL
  • Close and reopen Firefox

Note: These instructions work best on official browsers for laptop and iOS. Android support varies. More guides coming soon.
